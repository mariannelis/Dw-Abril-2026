Conceptos básicos

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para estructurar y crear el contenido de las páginas web.

CSS (Cascading Style Sheets) es el lenguaje que se utiliza para diseñar y dar estilo visual a las páginas web creadas con HTML.

JavaScript es un lenguaje de programación que se utiliza para agregar interactividad y dinamismo a las páginas web, permitiendo a los desarrolladores crear experiencias más ricas y atractivas para los usuarios.
