Lista de Eventos

A continuacion una lista definida con el conceptop de cada evento

  • click: ocurre cuando se hace clic en un elemento.
  • dblclick: ocurre al hacer doble clic.
  • mouseover: cuando el mouse entra sobre un elemento.
  • mouseout: cuando el mouse sale de un elemento.
  • mousemove: cuando el mouse se mueve.
  • mousedown: cuando se presiona un botón del mouse.
  • mouseup: cuando se suelta un botón del mouse.
  • keydown: cuando se presiona una tecla.
  • keyup: cuando se suelta una tecla.
  • keypress: cuando se mantiene presionada una tecla.
  • submit: cuando se envía un formulario.
  • change: cuando cambia el valor de un input.
  • input: cuando se escribe dentro de un campo.
  • focus: cuando un elemento recibe el foco.
  • blur: cuando un elemento pierde el foco.
  • load: cuando la página termina de cargar.
  • resize: cuando cambia el tamaño de la ventana.
  • scroll: cuando se hace scroll.
  • contextmenu: cuando se abre el menú con clic derecho.
  • copy: cuando se copia contenido.
